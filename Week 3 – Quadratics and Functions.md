## Quadratic Formula

So far, we have solved linear and quadratic equations — we have also solved some linear inequalities.

There are some quadratic equations that aren’t easy to factorize, so we employ other methods: completing the square and the quadratic formula.

Using the quadratic formula is the easiest and simplest solution to any quadratic equation. It’s defined as:

$$x = \frac{-b\pm\sqrt{b^2-4ac}}{2a}$$

Let's continue our last week’s quadratic work with some more examples.

### Examples

$1. \space 4x^2-10x+5=0$

$x = \frac{10\pm \sqrt {100-80}}{8}$

$= \frac {5 \pm \sqrt 5}{4}$   (factorizing $\sqrt 20$ as $\sqrt 4 \sqrt 5$)

1. $\frac {x}{4} = \frac {x+2}{2x} - \frac {3}{x}$

$= 4 (\frac {x+2}{2x} - \frac {3}{x})$

$= 4 (\frac {x+2-6}{2x})$

$2x^2 = 4x-16$

And finally,

$2x^2-4x+16=0$

or

x^2 -2x+8=0

Thus,

$x = \frac {2 \pm \sqrt {4-32}}{2}$

$= 1 \pm \sqrt {-7}$ $= 1 \pm 7i$

## Functions

We have been solving equations, which means finding the value of unknown variables (usually $x$) satisfying the given equation’s value.

This is quite useful in specific cases (add some examples). However, there are some other circumstances that require a general rule (or formula in simple words).

For example, if $x$ represents the radius of a circle, then its area can be defined as $\pi x^2$. Here, any value of $x$ will correspond to the respective area. Since area is entirely dependent on just the value of $x$, it means it’s a function of $x$.

Mathematically, we write it as $f(x) = …$ 

For example,

- $f(x) = 2x^2+4$
- $f(x) = 3.64x$      (formula for converting Qatari Riyals into USD)
- $f(x) = 2.54x$      (formula for converting inches into cms)

<aside>
💡

Please note that $f$ is just a _de facto_ standard; we can name a function as $g(x)$, $a(x)$ or anything.

</aside>

### Evaluating functions

Once we have established a function (as a proper algebraic expression), it's pretty easy to utilize it. Like 5’ (60 inches) can be converted into cms as:

$f(60) = 2.54(60) = 152.4cm$

**Example**: Find the values of $f(x)=3x^2 -9$ for $x=0,1,2,3$.

If $x=0$, we will have $f(x)=f(0)=-9$.

Similarly, $f(1)=-6$, $f(2)=3$ and $f(3)=18$.

### Plotting functions

**A function must have only one output for a given value/input**. Usually, functions give a proper output for almost any value — positive, negative, fractions, irrational (i.e. any real number). Since numbers are infinite, so it doesn’t make any sense to keep on evaluating the function on different values. Instead, it is better and far easier to analyse them by plotting them.

<aside>
💡

Note: For plotting a function, we take the variable on the x-axis and the function’s output, $f(x)$, on the y-axis.

</aside>

# Quantitative-Reasoning
These are lecture notes for the Quantitative Reasoning Course (2026).

There are some general points regarding the class:

- You can use AI for researching things, but not for drafting your assignments or emails. 
- Mid-term will be partially open book as you can bring an A4 sheet as a cheat sheet. Inevitably, the level of mid will be harder than a closed book exam too.
- Use of computational tools like Excel, Python etc is encouraged but not forced. 
- This course is a precursor to the Quantitative Reasoning II course in a later semester and hence the foundations you build there are quite important.
